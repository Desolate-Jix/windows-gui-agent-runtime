# Contributing

Issues and pull requests are welcome. Keep changes small, add focused tests, and preserve the separation between Agent, Operation, Gate, Trace, and reusable assets.

Before submitting:

```powershell
pytest -q
python examples\local_demo.py
```

Do not commit credentials, personal data, website screenshots, model weights, copied datasets, or real runtime traces. Contributions must be your own work or carry a compatible license with clear attribution.
