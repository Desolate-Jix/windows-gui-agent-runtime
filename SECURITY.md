# Security Policy

This experimental project is not production-ready. Do not use it for destructive, financial, account, submission, or safety-critical actions.

Please use the repository's **Security** tab and **Report a vulnerability** to submit a private GitHub Security Advisory. Do not publish exploit details in a public issue. If private vulnerability reporting is unavailable, open a public issue containing only a request for a private contact channel—do not include sensitive technical details.

Never include credentials, cookies, personal information, or private traces in a report.

The baseline intentionally blocks destructive action vocabulary and requires current-screen evidence, but these controls are not a security certification.
